FAQ pelanggan.

Maklumat ringkas sebelum anda membuat tempahan.

Adakah harga semua bug RM5?

Tidak semestinya. RM5 ialah harga permulaan untuk semakan atau isu kecil. Harga akhir bergantung pada skop dan kerumitan, dan akan dipersetujui dahulu.

Bagaimana cara membuat tempahan?

Isi borang, semak mesej yang dijana, kemudian hantar melalui WhatsApp. Jika API tempahan dikonfigurasi, permintaan juga direkodkan pada dashboard.

Perlu beri kata laluan atau token API?

Jangan hantar kata laluan, token rahsia, recovery code atau maklumat sensitif melalui borang. Kongsi hanya log yang telah disunting untuk membuang rahsia.

Adakah semua projek boleh dibaiki?

Belum tentu. Projek akan diperiksa dahulu. Kerja hanya dimulakan selepas skop, harga dan batasan dipersetujui.

Adakah website ini menyimpan tempahan secara automatik?

WhatsApp berfungsi tanpa konfigurasi tambahan. Penyimpanan tempahan ke dashboard memerlukan tetapan Supabase dan pemboleh ubah persekitaran Vercel seperti dalam README.
